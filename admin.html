📲 Add from WhatsApp

Dragging not working? Set it up manually instead — takes under a minute, no dragging needed.

  1. Make sure your browser's bookmarks bar is showing (usually Ctrl+Shift+B, or Cmd+Shift+B on Mac).
  2. Right-click anywhere on the bookmarks bar and choose Add page / Add bookmark.
  3. For the name, type: Add from WhatsApp
  4. For the URL, click the button below to copy it, then paste it into the URL field.
  5. Save. Done — click that bookmark any time you're on a WhatsApp Web chat.
